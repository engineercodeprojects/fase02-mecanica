# US-23: Documentacao Swagger das APIs

**User Story:** Como Desenvolvedor, quero que todas as APIs estejam documentadas via Swagger, para facilitar o consumo e testes dos endpoints.

**Prioridade:** Media
**Story Points:** 2
**Status:** To Do
**DDD Domain:** Todos os dominios
**DDD Layer:** Interface

## Criterios de Aceite

- [ ] Swagger configurado no NestJS
- [ ] Todos os endpoints documentados com descricao
- [ ] DTOs com decorators de validacao e documentacao
- [ ] Exemplos de request/response em cada endpoint
- [ ] Agrupamento por modulo/bounded context
- [ ] Acessivel em /api
