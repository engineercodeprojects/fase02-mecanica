# US-04: Catalogo de Servicos

**User Story:** Como Gestor, quero cadastrar e gerenciar os servicos oferecidos pela oficina (nome, descricao, preco base, tempo estimado), para que possam ser incluidos nas ordens de servico.

**Prioridade:** Alta
**Story Points:** 3
**Status:** To Do
**DDD Domain:** Servico (Bounded Context: Catalogo)
**DDD Layer:** Domain + Interface

## Criterios de Aceite

- [ ] CRUD completo de servicos
- [ ] Campos: nome, descricao, preco base, tempo estimado em horas
- [ ] Preco deve ser valor positivo
- [ ] Listar servicos com paginacao e filtro por nome
- [ ] Documentacao Swagger para todos os endpoints
